# 📄 Smart ATS Resume Builder

An intuitive, responsive web application designed to help job seekers create clean, professional, and ATS-friendly (Applicant Tracking System) resumes effortlessly.

🌐 **Live Demo:** [smartatscv.com](https://smartatscv.com)

---

## ✨ Features

- **ATS-Optimized Formatting:** Structured layouts designed to pass Applicant Tracking Systems seamlessly.
- **Real-Time Preview:** Live editing and instant formatting updates.
- **Export to PDF:** Download clean, high-quality, print-ready resumes with a single click.
- **Mobile & Desktop Responsive:** Fully optimized for seamless use across all devices.
- **Privacy-Focused:** All data processing occurs directly in the user's browser—no sensitive personal information is stored externally.

---

## 🛠️ Built With

- **HTML5:** Semantic document structure
- **CSS3:** Responsive styling, flexbox/grid layout, and print optimization
- **JavaScript (Vanilla):** Dynamic DOM manipulation and state management
